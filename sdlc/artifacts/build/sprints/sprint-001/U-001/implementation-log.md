## Environment Constraints

1. **JDK requirement**: Build requires JDK 17 (found at `~/.jdks/jbr-17.0.14`). Set `JAVA_HOME` to this path. Default JDK 22 on PATH is incompatible (Groovy build script compilation fails at class file version 65).

2. **NIO Selector workaround**: On Windows with JDK 17/21, Gradle 7.5.1 fails to establish daemon loopback connection via Unix domain sockets. Workaround committed to `gradlew` (DEFAULT_JVM_OPTS) and `gradle.properties` (org.gradle.jvmargs). Additionally set `JAVA_TOOL_OPTIONS` in shell for daemon subprocess propagation.

3. **firebase-jobdispatcher:0.8.6**: Not available from scijava.org at time of implementation. Built from source (googlearchive/firebase-jobdispatcher-android tag v0.8.6) and published to `~/.m2/repository`. `mavenLocal()` added to allprojects repositories. **Future builders on other machines must either build this artifact locally or have it in their Gradle cache before running S1 build.**

## Notes

- `gradlew` and `gradle.properties` NIO socket workaround: these are environment-specific fixes for this Windows + JDK 17/21 + Gradle 7.5.1 combination. They are benign on other platforms (the system property is only consulted on Windows).
- The `mavenLocal()` addition addresses the firebase-jobdispatcher availability gap. Once S3 removes firebase-jobdispatcher (MU-005), `mavenLocal()` can be removed.
- `buildToolsVersion '29.0.2'` in `app/build.gradle` generates a warning but does not fail the build (AGP 7.4.2 auto-upgrades to 30.0.3). The `buildToolsVersion` line is left as-is per story scope constraints.
